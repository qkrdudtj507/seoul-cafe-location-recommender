# ☕ 서울시 카페 창업 입지 추천 시스템

> 서울시 상권 공공데이터로 개인 카페 창업 후보지를 점수화하고, **창업자 유형(페르소나)별로 맞는 상권**을 추천하는 프로젝트입니다.
> 2026 BIGDATA SUMMER SCHOOL · TEAM 커머셜 (김준형, 구민준, 이지수, 박영서, 김현수)

## 📌 문제 정의

- 서울 카페는 2025년 기준 21,388곳입니다. 2025년 1분기 커피음료점 폐업률(4.0%)이 개업률(3.1%)을 넘어섰고, 5년 생존율은 34.6%로 생활업종 평균(39.6%)보다 낮습니다.
- 상권 데이터는 공개되어 있지만 유동인구·매출 숫자만 나열되어 있어서 **"내 가게가 잘 될 자리인지"** 판단하기 어렵습니다.
- 그래서 예비 창업자는 발품을 팔아도 비교 기준이 없어 결국 감으로 자리를 정하게 됩니다.

**타깃 페르소나** — 김바리(32), 개인 카페 창업을 앞둔 바리스타
> "감이 아니라 숫자로 후보지를 좁히고 싶다. 수요·경쟁·임대료를 한 화면에서 비교한 뒤 3~5곳으로 추려 계약하고 싶다."

## 🧭 분석 흐름: 왜 레이어 구조가 되었나

이 프로젝트의 핵심은 **처음 세운 접근이 통하지 않아서 구조를 바꾼 과정**입니다.

| 단계 | 시도 | 결과 | 다음 판단 |
|---|---|---|---|
| ① 매출 예측 모델 | 점포당 매출을 타깃으로 변수 선택(37 → 10개) 후 예측 | **R² = 0.352** | 카페 매출은 브랜드력·메뉴·인테리어처럼 입지 데이터에 없는 요인의 영향이 커서, 입지 변수만으로 설명되지 않음 → 예측 대신 **해석 가능한 규칙 기반 점수**로 전환 |
| ② Layer 1. 스코어링 | 수요·성과·여유·안정성 4축 종합점수 | 상권의 '좋고 나쁨'은 구분됨 | 하지만 같은 점수라도 **누구에게 맞는 상권인지**는 알 수 없음 → 창업자 유형을 반영할 레이어 추가 |
| ③ Layer 2. 페르소나 | 창업자 유형 5가지별 적합도 | 유형마다 다른 TOP 상권 도출 | 대시보드·웹 서비스로 제공 |

## 🗂️ 데이터

**서울시 상권분석서비스** 8종 + **국토교통부 상업용 부동산 실거래가**를 상권 코드 기준으로 통합했습니다.

| 데이터 | 용도 |
|---|---|
| 추정매출 | 업종별 매출 규모, 상권 활성도 |
| 소비 | 상권별 소비 규모·특성 |
| 상주인구 / 직장인구 | 거주·직장 기반 배후 수요 |
| 점포 | 점포 현황, 경쟁도 |
| 집객시설 | 주변 시설에 따른 유동 수요 |
| 길단위인구 | 실제 이동·유동 수요 |
| 상권영역 | 공간 결합, 상권 단위 설정 |
| 상업용 부동산 실거래가 (국토교통부) | 상권 중심 반경 500m 버퍼로 결합 → 매매단가 산출 |

### 전처리

- **업종**: 커피-음료
- **분석 범위**: 총 1,056개 상권에서 아래 컷오프 적용
  - 점포 수 3개 이하 상권 제외
  - 매출 하위 20% 상권 제외
- **버퍼**: 상권 반경 500m 범위의 매매 데이터 매칭
- **정규화**: 상권 간 편차가 30배를 넘는 지표가 많아 min-max 정규화
- **통합 결과**: 9개 데이터셋, 4,218행 × 111열 (상권 × 분기)

## 🔬 ① 매출 예측 모델 테스트 (채택하지 않음)

| 단계 | 변수 수 |
|---|---|
| 데이터 정제 | 37 → 27 |
| 1차 상관계수 필터 (\|r\| > 0.9 제거) | 27 → 17 |
| 2차 VIF 필터 (VIF > 10 제거) | 17 → 13 |
| 3차 RF + Lasso 중요도 | 13 → 10 |

최종 변수: 총 유동인구, 유동인구 밀도, 청년 유동인구 비율, 20대 상주인구, 폐업률, 여가 소비지출, 프랜차이즈 점포수, 개업률, 은행 수, 교통 접근성

→ R² = 0.352에 그쳐, 매출을 직접 예측하는 대신 아래의 규칙 기반 스코어링을 사용했습니다.

## 🏗️ ② Layer 1 — 스코어링

각 지표를 **Z-score**로 표준화해 단위를 통일하고, 4개 축을 **0~100 백분위 점수**로 변환한 뒤 단순 평균했습니다.

| 축 | 질문 | 구성 지표 |
|---|---|---|
| **수요** | 손님이 있는가 | 유동인구·직장인구·상주인구, 20~30대 유동 비중 |
| **성과** | 얼마나 팔리는가 | 점포당 매출, 점심시간대 매출 비중 |
| **여유** | 경쟁이 얼마나 있는가 | 점포당 시장규모, 수요 대비 공급률 |
| **안정성** | 비용이 감당되는가 | 폐업률, 반경 500m 매매단가 |

```
최종 점수 = 0.25 × 수요 + 0.25 × 성과 + 0.25 × 여유 + 0.25 × 안정성
```

### 결과 — 카페 입지 추천 TOP 15

길동역 · 보라매공원 · 삼전역 4번 · 서울지방병무청 · 신설동역 · 서초3동사거리 · 구로구청 · 종암중학교 · 은평구청 · 영등포역(영등포) · 가산디지털단지 · 포스코사거리 · 등촌역 · 역삼역 · 서울대병원

- **대형 검증형**: 카페가 100개 넘게 있어도 수요가 압도적인 상권 (가산디지털단지 178개, 역삼역 131.5개)
- **소형 실속형**: 카페 3~10개, 폐업률 0%인 저경쟁 상권

두 전략이 상위권에 함께 나타났습니다. 수요-여유 산점도에서도 **"경쟁이 없다"와 "장사가 된다"는 다르다**는 점이 확인됐습니다. 경쟁이 적은 상권 중 상당수는 수요도 낮았습니다.

### 점수 분위별 성과

종합점수 1분위 → 5분위로 갈수록
- 점포당 매출 중앙값: 966만 원 → 6,042만 원 (약 6.3배)
- 폐업률 중앙값: 5.5% → 2.75% (절반)

> ⚠️ 점포당 매출은 성과 축에, 폐업률은 안정성 축에 이미 포함되어 있어서 이 결과는 독립적인 검증이 아닙니다. 점수가 의도대로 계산되었는지 확인하는 용도로만 해석해야 합니다. (아래 '한계' 참고)

## 👥 ③ Layer 2 — 페르소나

종합점수만으로는 상권이 좋은지 나쁜지는 알 수 있지만, **누구를 위한 상권인지**는 구분하기 어렵습니다. 그래서 창업자 유형 5가지별로 핵심 지표를 따로 묶어 적합도(0~100)를 계산했습니다.

| 유형 | 핵심 구성 지표 | 추천 카페 콘셉트 |
|---|---|---|
| 직장인형 | 직장인구, 평일 유동인구, 11~14시 유동인구, 20~30대 직장인구 | 테이크아웃, 오피스 배달형 |
| 학생청년형 | 10~20대 유동인구, 대학교 수, 문화·여가 지출, 20대 비중 | 저가 커피, 디저트, 스터디카페 |
| 주거가족형 | 상주인구, 총 가구 수, 아파트 가구 수, 주말 유동인구 | 동네 카페, 베이커리, 브런치 |
| 트렌드여가형 | 20~30대 유동 비중, 여가·문화·유흥 지출, 총 소비지출 | 감성 카페, 디저트, 스페셜티 |
| 관광핵심상권형 | 총 유동인구, 집객시설 수, 상권 면적, 외부 방문 비율, 총매출 | 대형·테마·프리미엄 카페 |

### 결과 — 페르소나별 TOP 1 상권

| 페르소나 | 상권 | 자치구 | 적합도 | 종합점수 |
|---|---|---|---|---|
| 직장인형 | 명동·남대문 관광특구 | 중구 | 99.9 | 71.0 |
| 학생청년형 | 연남동(홍대) | 마포구 | 95.2 | 59.1 |
| 주거가족형 | 망리단길 | 마포구 | 86.5 | 50.1 |
| 트렌드여가형 | 신림역 5번 | 관악구 | 98.7 | 47.7 |
| 관광핵심상권형 | 신촌역 | 서대문구 | 97.7 | 63.0 |

종합점수가 높지 않아도 특정 창업자에게는 가장 잘 맞는 상권이 있다는 점이 레이어를 분리한 이유입니다. 예를 들어 페르소나 김바리처럼 빠른 회전율과 박리다매를 노린다면, 평일 점심 오피스 인구가 많은 직장인형 상권(1위 명동·남대문 관광특구, 2위 강남역)이 맞습니다.

## 🖥️ 서비스화

- **Snowflake**: 스코어링 결과를 테이블(`COMMERCIAL.SALE.COFFEE_SCORED_4AXIS`)로 적재하고 SQL로 조회
- **Streamlit in Snowflake**: 페르소나를 고르면 TOP 5 상권, 적합도 × 종합점수 비교, 추천 상권 지도를 보여 주는 대시보드
- **웹 서비스(BIZ SCOPE)**: Next.js 웹앱과 연동해 실제 서비스 형태로 확장

## ⚠️ 한계와 향후 과제

**한계**
- 4축 가중치(각 0.25)는 데이터로 추정한 값이 아니라 동일 비중으로 둔 것입니다. 가중치를 바꿨을 때 순위가 얼마나 달라지는지 민감도 분석이 필요합니다.
- 분위별 성과 비교에 쓴 점포당 매출·폐업률이 점수 산식에 포함되어 있어서, 점수의 예측력을 검증하려면 산식에 쓰지 않은 지표나 이후 분기 데이터로 다시 확인해야 합니다.
- 비용 지표로 임대료 대신 매매단가를 사용했습니다.

**향후 과제**
1. **업종 확장**: 음식점, 미용실 등 상권 편차가 큰 업종에도 같은 방법론 적용
2. **비용 지표 고도화**: 상권별 임대료 데이터 확보 시 안정성 축 정확도 향상
3. **시계열 반영**: 2021년부터 쌓인 원천 데이터로 상권 성장·쇠퇴 추세 분석
