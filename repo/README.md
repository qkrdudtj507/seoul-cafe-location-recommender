## 📌 프로젝트 소개

서울시 커피음료점은 2025년 1분기 기준 폐업률(4.0%)이 개업률(3.1%)을 앞지르는 상황에 놓여 있습니다. 상권 데이터는 이미 공개되어 있지만, 유동인구·매출 숫자만 나열될 뿐 "내 가게가 잘 될 자리인지"를 판단하기는 쉽지 않습니다.

이 프로젝트는 서울시 상권분석서비스 원본 데이터(분기 × 상권, 168개 변수, 약 8.4만 행)에서 **커피-음료 업종만 추출**해 4개 분기를 평균 집계하고, **상권 1,058개 단위로 카페 창업 적합도를 점수화**해 상위 후보지를 추천합니다.

- 🎯 **타깃**: 감이 아니라 숫자로 후보지를 좁히고 싶은 예비 카페 창업자
- 📊 **핵심 산출물**: 상권별 종합 추천 점수, TOP N 추천 리스트
- 🖥️ **시각화**: Streamlit 대시보드 (Snowflake 연동 지원)

전체 분석 배경·해석은 [`reports/카페_입지추천_분석리포트.pdf`](reports/카페_입지추천_분석리포트.pdf)를 참고하세요.

## 🔍 분석 방법론 & 코드 매핑

| 단계 | 내용 | 코드 |
|---|---|---|
| 1. 데이터 준비 | 커피-음료 업종 필터링 → 상권 단위 분기 평균 집계 → 결측 상권 제외 → 파생변수 생성 | [`src/preprocessing.py`](src/preprocessing.py) |
| 2. 변수 선택 | 상관계수 필터(\|r\|>0.9) → VIF 필터(VIF>10) → RF+Lasso 결합 중요도 상위 10개 | [`src/feature_selection.py`](src/feature_selection.py) |
| 3. 스코어링 | 성과잠재력(RF out-of-fold 예측 백분위) 50% + 수요-공급 갭 50% | [`src/scoring.py`](src/scoring.py) |
| 4. 실행/저장 | 위 3단계를 순서대로 실행하고 결과 CSV 저장 | [`src/pipeline.py`](src/pipeline.py) |
| 5. 시각화 | 상권 탐색 대시보드 | [`dashboard/app.py`](dashboard/app.py) |
| 6. (선택) 적재 | 결과를 Snowflake 테이블로 업로드 | [`src/load_to_snowflake.py`](src/load_to_snowflake.py) |

VIF는 `statsmodels` 없이 `sklearn.LinearRegression`의 R²로 직접 계산합니다 (`1 / (1 - R²)`), 의존성을 줄이기 위한 선택입니다.

### 종합점수 산식

```
종합점수 = 0.5 × 성과잠재력_점수 + 0.5 × 수요공급갭_점수   (0~100 백분위)

성과잠재력_점수 = RF 5-fold OOF 예측(점포당_매출)의 백분위
수요공급갭_점수 = zscore_avg(총_유동인구_수, 총_상주인구_수, 총_직장_인구_수, 주말유동인구_비율)
                 − zscore_avg(similr_induty_stor_co, 카페_밀도)   → 백분위 변환
```
